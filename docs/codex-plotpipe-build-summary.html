02 - Core Pipeline

The Pipeline Codex Built

Codex built PlotPipe as a local Node.js / TypeScript pipeline that turns a PlotTeaFiles story script into a vertical MP4. The pipeline validates the story, creates narration, generates word-level captions, prepares visual scenes, and renders with Remotion.

Script parsingAdded Zod validation for JSON and TypeScript story scripts.
VoiceoverIntegrated OpenAI TTS by default, with ElevenLabs kept as an optional provider.
CaptionsUsed OpenAI Whisper to create word-level timestamp data for karaoke-style captions.
Image/B-roll systemStarted with local assets and Pexels, then moved toward generated AI images for better story match.
Remotion renderCreated React-based video composition, captions, hook screen, vignette, B-roll motion, and MP4 rendering.
CLI commandsAdded commands for full runs plus separate voiceover, subtitles, compose, and render stages.

Main files Codex created or updated

  • src/cli.ts - CLI entry point, commands, options, and pipeline orchestration.
  • src/pipeline/parse.ts - story schema and validation.
  • src/pipeline/voiceover.ts - OpenAI / ElevenLabs narration generation.
  • src/pipeline/subtitles.ts - Whisper transcription and word timestamps.
  • src/pipeline/compose.ts - converts story, audio, captions, and visuals into Remotion props.
  • src/pipeline/render.ts - Remotion render handling.
  • src/pipeline/imagegen.ts - AI image generation fallback path for stronger visuals.
  • src/remotion/* - the video composition and visual components.

04 - Testing Work

What Codex Tested While Building

The testing work was practical: build the pipeline, run it against the sample story, inspect generated outputs, compare visual strategies, and adjust the workflow based on the results.

Test / outputWhat it provedResult
out/tornado.mp4 Confirmed the basic Remotion render path could produce an MP4. Worked, but visuals were placeholder-like.
out/tornado-pexels.mp4 Tested stock-video B-roll from Pexels. Worked technically, but visuals felt generic.
out/tornado-pexels-v2.mp4 Tested improved Pexels keyword refinement. Better search behavior, still not strong enough.
out/tornado-pexels-photos.mp4 Tested photo-only stock output as an alternative. Still too stock-like for the channel style.
out/tornado-ai.mp4 Tested AI-generated image visuals. Best direction compared with stock footage.
out/tornado-gemini.mp4 Tested Gemini as the image provider. Gemini hit 429 Too Many Requests; OpenAI fallback generated the usable images.
out/tornado-ai-cinematic.mp4 Tested multi-shot AI images per segment with cinematic motion. Best result from the Codex testing phase.

The testing conclusion was that Pexels did not match the dramatic story format well enough. The strongest approach was AI-generated cinematic stills, multiple shots per segment, slow motion, cuts, grain, vignette, and captions over narration.
